# Checklist de auditoría cruzada

- [ ] Existe `main`.
- [ ] Existe `develop`.
- [ ] La rama cumple la convención.
- [ ] `core.hooksPath` apunta a `.githooks`.
- [ ] `pre-commit` bloquea secretos.
- [ ] `commit-msg` valida mensajes.
- [ ] Existe `.gitignore`.
- [ ] Existe `CONTRIBUTING.md`.
- [ ] Existe política documentada.
- [ ] PR apunta a rama correcta.
- [ ] Existe reviewer.
- [ ] Comentarios resueltos.
- [ ] Hay trazabilidad con Work Item.
- [ ] No hay secretos publicados.
- [ ] El equipo explica cómo resolver un conflicto.
